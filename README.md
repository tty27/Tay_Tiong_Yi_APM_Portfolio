# Tay Tiong Yi APM Portfolio

Recruiter-focused static portfolio.

## Before publishing
1. Replace the LinkedIn and GitHub placeholder URLs in `index.html`.
2. Put your final CV PDF in this folder and name it exactly `resume.pdf`.
3. The Download résumé buttons will then work.

## Local preview
Run `python -m http.server 8000` in this folder and open http://localhost:8000

## Deploy
Upload the folder to GitHub and connect it to Vercel, Netlify or GitHub Pages.
